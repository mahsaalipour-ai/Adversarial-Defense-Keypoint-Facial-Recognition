چطور اجرا کنی — خیلی کوتاه (از داخل فولدر steps)

1. بزن:
. .\env.ps1

2.  بکاپ اولیه:
mkdir ..\data\_keep_000001_v1 -ea 0
Copy-Item ..\data\step2\000001_* ..\data\_keep_000001_v1 -ErrorAction SilentlyContinue
Copy-Item ..\data\step3_out\000001_* ..\data\_keep_000001_v1 -ErrorAction SilentlyContinue

3. اجرای مرحله ۲ (تولید perturbation مطابق پارامترهای exploratory):
python .\step2_warp.py

4. اجرای مرحله ۳ (بهینه‌سازی ماسک):
python .\step3_ganmask.py

خلاصه تر:
. .\env.ps1
python .\step2_warp.py
python .\step3_ganmask.py

برای  فایل env.ps1:


1.نسخهٔ «طبق مقاله» (رسمی — کم‌تحریک) — برای متن رساله یا حالتِ محافظه‌کار:
# env_paper.ps1
$env:STEP2_PCT_GEOM = "0.02"
$env:STEP2_JITTER   = "5"
$env:STEP2_FLOW_SIGMA = "1.0"

$env:USE_GAN   = "0"
$env:ITERS     = "3000"
$env:ETA_PUSH  = "8.0"
$env:LR_MASK   = "0.02"
$env:HEADLESS  = "1"

2.نسخهٔ «تقویتی ولی طبیعی» (برای اسلاید و نمایش جلوی داورها) — هدف: اثر دیده شود ولی تصویر خیلی به‌هم‌ریخته نشود (استفاده از GAN کمک می‌کند طبیعی‌تر بماند):

# env_expl.ps1
$env:STEP2_PCT_GEOM = "0.07"
$env:STEP2_JITTER   = "8"
$env:STEP2_FLOW_SIGMA = "1.0"

$env:USE_GAN   = "1"        # use GAN prior -> کمتر خشونت تصویری
$env:ITERS     = "4000"
$env:ETA_PUSH  = "10.0"
$env:LR_MASK   = "0.03"
$env:HEADLESS  = "1"
